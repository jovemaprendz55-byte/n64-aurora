# Avisos de código aberto

O N64 Aurora Emulator foi planejado para integrar o **Mupen64Plus Android Edition (AE)**, um frontend Android do Mupen64Plus distribuído sob a **GNU General Public License, versão 3.0**. A integração de seu núcleo e de seus módulos nativos exige que a distribuição final preserve os avisos aplicáveis, identifique alterações e ofereça o código-fonte correspondente do release sob os termos da licença.

O repositório de referência é [mupen64plus-ae/mupen64plus-ae](https://github.com/mupen64plus-ae/mupen64plus-ae). A distribuição final deve acrescentar aqui o URL público exato do código-fonte correspondente ao APK/AAB e todas as atribuições dos plugins efetivamente incluídos no build.

Este projeto não inclui ROMs, BIOS, arte de jogos ou outros arquivos de jogos. O usuário deve importar somente arquivos dos quais detenha o direito de uso.
